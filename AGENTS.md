# Repository Instructions

Read the [project contract](docs/project-contract.md) before repository work,
then read the task-specific documents it names. The contract contains the
repository invariants, task routes, collaboration rules, and definition of
done.

Use the capabilities and permissions of the active harness. Claude-specific
hooks, skills, and rules are not automatically available to other agents.
Repository Git hooks apply only when configured; see the project contract.
