# Data Sources and Reuse

These frozen files support reproducible teaching examples. They are observational data, and their inclusion does not transfer ownership or grant rights beyond the sources' applicable terms.

## Palmer Penguins

`penguins.csv` is the curated package CSV at commit [`8957207b78d6ccd1b4654a9dd9c9041b657478ab`](https://github.com/allisonhorst/palmerpenguins/tree/8957207b78d6ccd1b4654a9dd9c9041b657478ab). Its SHA-256 is `f204db2c753b0937caac3cb35258562c14f073e4bbc76be24b4c51ce22767a93`. The package authors identify the data as CC0 under the [CC0 1.0 public-domain dedication](https://creativecommons.org/publicdomain/zero/1.0/) and provide dataset citations in their [pinned README](https://github.com/allisonhorst/palmerpenguins/blob/8957207b78d6ccd1b4654a9dd9c9041b657478ab/README.md). They ask those publishing the data to contact Kristen Gorman about analysis and possible collaboration; this is an author request, not presented as a CC0 licence condition. No contact was made for this primer.

Cite Gorman, K. B., Williams, T. D. and Fraser, W. R. (2014), [Ecological Sexual Dimorphism and Environmental Variability within a Community of Antarctic Penguins](https://doi.org/10.1371/journal.pone.0090081), and the dataset records: [Adélie](https://doi.org/10.6073/pasta/98b16d7d563f265cb52372c8ca99e60f), [Gentoo](https://doi.org/10.6073/pasta/7fca67fb28d56ee2ffa3d9370ebda689), and [Chinstrap](https://doi.org/10.6073/pasta/c14dfcfada8ea13a17536e73eb6fbe9e). The 344 rows contain missing values and uneven species–island coverage; model subsets and interpretation are described in the examples.

## Package-Derived Salamanders

`Salamanders.rda` is the glmmTMB package object from commit [`c311085c19a50af9a8e930352885313897333b7f`](https://github.com/glmmTMB/glmmTMB/blob/c311085c19a50af9a8e930352885313897333b7f/glmmTMB/data/Salamanders.rda); SHA-256 `cca69c7eb8488d7932217ccc623a815105eb3e522f4debcb1841342c31bfc389`. Its package-derived CSV, `salamanders-package.csv`, has SHA-256 `1dadca43a8c917da58cd341fb04f15c0ad22384a8487a33dc3f6b77516bf8874` and is generated by `examples/prepare_data.R` with the pinned R container. That script writes a temporary copy and verifies its hash against the frozen CSV; it does not alter this directory.

The [pinned package documentation](https://github.com/glmmTMB/glmmTMB/blob/c311085c19a50af9a8e930352885313897333b7f/glmmTMB/man/Salamanders.Rd) identifies the study and requests both citations: Price, S. J. et al. (2016), [Effects of mountaintop removal mining and valley filling on the occupancy and abundance of stream salamanders](https://doi.org/10.1111/1365-2664.12585), and Price, S. J. et al. (2015), [Dryad data package](https://doi.org/10.5061/dryad.5m8f6). [Dryad's metadata](https://datadryad.org/api/v2/datasets/doi%3A10.5061%2Fdryad.5m8f6) declares the original dataset CC0-1.0; the [pinned package declaration](https://github.com/glmmTMB/glmmTMB/blob/c311085c19a50af9a8e930352885313897333b7f/glmmTMB/DESCRIPTION) states AGPL-3 for glmmTMB. The [GNU AGPL version 3 licence text](https://www.gnu.org/licenses/agpl-3.0.html) and [CC0 1.0 legal code](https://creativecommons.org/publicdomain/zero/1.0/legalcode) are available from their publishers. The package documentation does not separately state a licence for its data transformations; neither declaration alone is represented as resolving all rights for the packaged material.

The original Dryad file was not obtained, and this package-derived object and conversion are not claimed to be byte-identical to it. The package contains 644 records for 23 sites, four sample occasions and seven species/stage categories. The package documentation describes scaled covariates; do not interpret the scaled values as original physical units. A recorded zero or non-detection does not establish true absence, and no effort offset is inferred from this dataset.
